# 模板与 OOXML 协议

用户指定“与某篇一模一样”时，参考文档是唯一格式权威。不得凭视觉印象近似重做。

## 必须读取

- `word/document.xml`
- `word/styles.xml`
- `word/numbering.xml`
- 页面和节属性
- 元信息表格属性

## 复制原则

- 深拷贝参考段落的 `w:pPr` 和示例 run 的 `w:rPr`。
- 保持 style 名称、字体、字号、粗体范围、段前／段后距、行距、首行／悬挂缩进、`numId` 和 `ilvl`。
- 保持标题、元信息表、“主要结论”和“访谈纪要”的 XML 顺序。
- 保持页面尺寸、页边距、表格宽度、边框、单元格边距、空白段落和分页行为。
- 引导语和正文需要不同粗体范围时，分别克隆对应 run。
- 不得通过统一设置字体的辅助函数覆盖模板原有属性。

## 默认模板参数

`assets/template_minutes.docx` 提供以下基线；用户另行指定模板时，以实测值覆盖：

| 元素 | 参数 |
|---|---|
| 标题 | 黑体 16pt；段后 360 twips |
| 一级标题 | 黑体 12pt |
| 元信息 | 楷体 11pt；标签粗体、值常规体 |
| 主要结论 | 楷体 11pt；引导语粗体；`numId=7, ilvl=0` |
| 一级章节 | 楷体 11pt 粗体；`numId=13, ilvl=0` |
| 二级标题 | 楷体 11pt 粗体；`numId=10, ilvl=1` |
| 正文要点 | 楷体 11pt；引导语粗体；`numId=4, ilvl=1` |

## 局部修订

1. 复制原件作为修改母版。
2. 按完整文本或稳定锚点定位待改段落。
3. 仅替换必要 run 的文本；新增段落克隆同层级原段落。
4. 比较修改前后的段落文本和关键 OOXML 部件。
5. 范围外变化必须回退。

## 分页

主要结论结束后优先对“访谈纪要”标题使用 `pageBreakBefore`。如渲染器行为不同，再采用显式分页符。不得机械叠加两种分页方式；最终 PDF 中不得出现空白页。
