# 模板与 OOXML 协议

用户指定“与某篇一模一样”时，参考文档是唯一格式权威。不得凭视觉印象近似重做。

本文件中的规则属于强制格式要求，不得被通用 Word 美化、字体兼容或文档设计建议覆盖。默认模板是完整的内部企业江滨格式模板；标题、元信息、编号、字体、间距、粗体范围、分页和 OOXML 关系均不得擅自改变。

## 必须读取

- `word/document.xml`
- `word/styles.xml`
- `word/numbering.xml`
- 页面和节属性
- 元信息表格属性

## 复制原则

- 深拷贝参考段落的 `w:pPr` 和示例 run 的 `w:rPr`。
- 保持 style 名称、字体、字号、粗体范围、段前／段后距、行距、首行／悬挂缩进、`numId` 和 `ilvl`。
- 保持标题、元信息表、“主要结论”和“访谈纪要”的 XML 顺序。
- 保持页面尺寸、页边距、表格宽度、边框、单元格边距、空白段落和分页行为。
- 引导语和正文需要不同粗体范围时，分别克隆对应 run。
- 不得通过统一设置字体的辅助函数覆盖模板原有属性。
- 不得把黑体、楷体、宋体或模板西文字体替换为苹方、冬青黑体、微软雅黑、Arial、Calibri 等“当前机器可用字体”。渲染环境缺字体时保留 Word 本体中的规范字体名称，并在视觉审核环境中解决字体安装问题。
- 不得重新保存模板后再执行样式规范化；必须从参考模板直接深拷贝段落属性和 run 属性。
- 自动编号段落的文本不得包含手写章节号、序号、箭头或短横线。编号只来自模板 `numId` 和 `ilvl`。

## 默认模板参数

`assets/template_minutes.docx` 提供以下基线；用户另行指定模板时，以实测值覆盖：

| 元素 | 参数 |
|---|---|
| 标题 | 黑体 16pt；段后 360 twips |
| 一级标题 | 黑体 12pt |
| 元信息 | 楷体 11pt；标签粗体、值常规体 |
| 主要结论 | 楷体 11pt；引导语粗体；`numId=7, ilvl=0` |
| 一级章节 | 楷体 11pt 粗体；`numId=13, ilvl=0` |
| 二级标题 | 楷体 11pt 粗体；`numId=10, ilvl=1` |
| 正文要点 | 楷体 11pt；引导语粗体；`numId=4, ilvl=1` |

## 局部修订

1. 复制原件作为修改母版。
2. 按完整文本或稳定锚点定位待改段落。
3. 仅替换必要 run 的文本；新增段落克隆同层级原段落。
4. 比较修改前后的段落文本和关键 OOXML 部件。
5. 范围外变化必须回退。

## 标题、文件名与元信息

- 标题固定为：`{项目名称}-{访谈对象}{访谈类型}`。
- 文件名固定为：`{项目名称}_{访谈对象}{访谈类型}纪要_{YYYYMMDD}.docx`。
- 元信息字段固定为“访谈时间、访谈地点、访谈来源、访谈对象及其背景介绍、访谈人员”，不得改名或增加制作说明字段。
- “访谈对象及其背景介绍：”与对象信息保持同一段，不在冒号后换行。
- 未知元信息可以留空；不得写 `111`、`XXX`、`TBD`、“待补充”“待确认”等占位内容。

## 分页

主要结论结束后优先对“访谈纪要”标题使用 `pageBreakBefore`。如渲染器行为不同，再采用显式分页符。不得机械叠加两种分页方式；最终 PDF 中不得出现空白页。

## 程序化验收

默认模板以 `assets/template_manifest.json` 保存关键部件指纹。成稿必须运行：

```bash
python3 scripts/verify_docx_format.py /absolute/path/output.docx \
  --reference /absolute/path/reference.docx \
  --project "项目名称" \
  --subject "访谈对象" \
  --interview-type "专家访谈" \
  --date-compact YYYYMMDD
```

校验器会检查关键 OOXML 部件、模板外字体、段落与 run 属性、页面设置、表格属性、标题、文件名、元信息、重复手写编号和受控分页。任何错误均为不通过，不得交付。
