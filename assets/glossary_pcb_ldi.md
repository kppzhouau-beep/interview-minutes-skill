## 十、单位 / 数字 / 标点高频问题

- **米/微米/纳米混淆**:专家常说"35厘米"实指35μm,"500纳米"实指500nm,根据上下文反推
- **百分点 vs 板寸**:"5个板寸"=5个百分点
- **金额量级**:"5,600亿"和"5600个亿"是同义,中国习惯
- **中英标点不能混用**:Python代码内的中文文本里有英文`"`会导致语法错误,统一用中文`""`
- **冒号**:中文":"和英文":"在表格中视觉相同但XML不同,保持统一

## 通用使用方法

1. 读取原始转录后,**先做一遍grep扫描**:
   ```
   grep -nE '(止血|盛红|新奇威|普尔|靠卧室|七普雷特|玻璃机)' raw.txt
   ```
   定位常见错误。
2. 改写时**逐句对照专家原话**,每个公司名/数字都在本词典中找一遍。
3. 吃不准的用"等"模糊化,**不要乱猜**。
4. 最后用相同的grep再扫一遍生成的纪要,确保无残留。
