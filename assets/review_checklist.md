# 内容与版式双重独立审核检查表

生成docx后必须分别完成**内容独立审核**和**版式独立审核**。内容审核至少包含语言质量与事实／行业准确性两个子轮次；版式审核单独对模板结构、OOXML和逐页渲染结果负责。

---

## 内容独立审核（一）:语言质量

### 1. 错别字与误用词扫描

用grep批量扫描敏感词残留:

```bash
grep -nE '(止血|玻璃机|防汗|妨碍|盛红|盛虹|分红|宋红|新奇威|新奇辉|信息为|信息微|普尔|二宝|月亚|月亚|去发|柔性洗眼|套客|金元级|靠卧室|靠pose|麦克|生丸|圆桌|圆卓|杨卓|原则|原轴|袁卓|星期a|星期v|星际伪装|星际威|辛奇威|楼号|阻焊干磨|新津威|新机位|新机会|新企业|新津辉|科室|科四|做安|神经比对|玻璃机封装|TT为|7g为|teevee|展板|柔性面板)' output.txt
```

如有命中,逐项核对 `assets/glossary_pcb_ldi.md`。

### 2. 标点一致性

- ❌ 中英文双引号混用 → 统一中文"" ''
- ❌ 中英文括号 () （） 混用 → 在中文段落中统一中文（）
- ❌ 中英文冒号 : : 混用 → 统一一种(我推荐中文段落用中文:)
- ❌ 中英文逗号 , , 混用 → 不要混用

### 3. 句式与语气

- 报告腔过重?长排比、对仗句太多?适当口语化
- 出现连续3个以上"对吧"、"好像"、"应该是"等口语助词,删掉
- 结尾问句过多导致"乖学生感"?改为判断句
- 逐段检查主谓关系、指代对象、语序和上下文衔接,消除口语残句、机械拼接及逻辑跳跃
- 正文不得出现“专家认为”“专家提到”“专家估计”“按专家粗算”等机械归因；管理层、客户和内部人员不得被统称为“专家”
- 正式纪要不得出现“录音完整性”“覆盖范围”“资料边界”、时间戳、结束致谢或逐字稿制作过程说明
- 正式纪要不得出现“转写不清晰”“未作量化／测算”“具体数字记忆不清”“待核验”“待核”“口径待核”“须以资料复核”等内部编辑或质控说明
- 正式纪要不得自设“访谈范围与数据边界”“数字来源”“口算更正”“名称处理”等后台核验章节,也不得写“未能确认”“需另行核查”“原话为”“待版图数据确认”等成稿说明

### 4. 重复表达

- 同一段中同一信息出现2次以上,合并或删除
- 同一公司在同一section出现5次以上,适当代以"该公司""该厂家"

### 5. 数字与单位

- "微米"和"μm"统一(我推荐用μm)
- "亿元/亿人民币"统一(我推荐"亿元")
- "万元/万"统一
- 区间数字写法统一:"500-600亿"还是"500~600亿"?统一一种(我推荐用半角"-")

## 内容独立审核（二）:事实与行业准确性

### 1. 数字一致性

主要结论中的所有数字必须能在访谈纪要章节中找到出处。
列出主要结论里所有数字,逐一回溯到访谈纪要正文中确认。

### 2. 公司名/事实核对

**重点核对以下高频错误地点**:
- 厂区地点(亚利桑那/佐治亚州、合肥/南京、深圳/苏州等)
- 公司全称(科技/股份/集团/电子等后缀)
- 上市代码(板块+代码)
- 创始人/高管姓名

**公司与机构名称分类双重核验（逐项勾选）**:
- 只对计划写入或最终保留在正文的主体执行外部核验；用户已明确排除的项目介绍或公司不做无效查询
- 最终正文中的每个名称均能定位到本场原始转录,不是网络资料或模型新增
- 国内企业已用企查查＋公司官网或政府、交易所、监管机构等权威来源核验
- 政府、科研院所和高校已用官方网站＋主管部门、权威名录或其他权威公开来源核验
- 国外企业已用公司官网＋监管披露、行业协会、标准组织或其他权威行业来源核验
- 无法可靠验证且不影响主旨的名称已省略或泛化,没有猜测性替换
- 当前任务未暴露QCC工具时,已检查Server配置并使用`scripts/qcc_mcp_call.py --list-tools`尝试直连工具发现,没有把“工具目录0个”误判为企查查不可用
- QCC查询已遵循实体路由：简称先调`get_company_by_query`,完整工商名调`get_company_registration_info`,只有全称与统一社会信用代码同时存在时才调`verify_company_accuracy`
- 企查查原生与直连备用路径均失败时,已如实记录失败类型并使用企查查公开页面／`site:qcc.com`加权威一手来源替代,未虚构工具调用
- QCC直连过程未输出、记录或写入任何Bearer Token原文
- 音近名称无法唯一匹配时已删除名称或泛化为“相关厂商／供应商／科研院所”,没有猜测性替换
- 外部核验信息只用于纠正名称,没有把外部业务、数据、客户或判断补进纪要

### 3. 术语精确性

- **CD (Critical Dimension, 关键尺寸/线宽) vs Overlay (套刻精度/对位精度)** — 这两个绝对不能混。LDI做到6μm的是**线宽**,不是套刻精度
- **TSV vs TGV** — TSV是硅通孔,TGV是玻璃通孔,不要互换
- **CoWoS / CoPoS / Chip-on-Glass** — 演进关系不要写反
- **5阶HDI vs 5G HDI** — "5阶"是压合阶数,"5G"是通讯,完全不同概念
- **HBM / HDI / SLP** — 三个PCB细分品类,不要混用

### 4. 逻辑一致性

- 整段叙述中"先A后B"的因果是否对得上
- "X占比Y%、剩余Z%由W分摊"——X+Z是否等于100%
- 时间线("2019年布局、2024年量产")是否前后一致

### 5. 转录口径与外部资料冲突

外部资料只用于后台识别潜在转写错误。单场访谈纪要仅保留本场转录口径；不得把年报、其他访谈或网络信息并入正文，也不得自行解释差异原因。若用户另行要求综合分析，再在独立文件中并列不同来源及口径差异。

### 6. 不确定信息的处理

- 不确定公司名:省略名称或用“相关厂商／供应商／科研院所”泛化
- 不确定地点:不影响主旨时省略地点；不得写“地点待核”“未能确认”
- 不确定数字:回到原始转录复听；仍无法确认时省略争议数字或保留不含争议数字的事实,不得写“口径待核”
- 所有疑点只进入内部核验表或交付说明,不得作为正式纪要段落

### 7. 完整性与来源边界

- 逐条枚举本场转录中未被正文直接引用的内容,分别归类为重复、提问、串话、无关闲聊、无法归属或需补回
- 不得因篇幅较短就引入边界外内容；也不得因追求简短而遗漏独立事实、限定条件、阶段状态、否定性信息和风险
- 每个事实、数字、因果和判断必须能回指本场原始转录；不得混入其他受访人、项目材料、网络资料或模型推断
- 多场连续访谈先用时间轴、称呼、履历、职责和话题切换确认边界；预定日程只作辅助，身份不明的内容不得强行归属

## 版式独立审核:视觉与模板一致性(必做)

### 0. 强制程序化校验

先运行格式守门器；只有出现 `FORMAT CHECK PASSED` 才进入逐页视觉检查：

```bash
python3 scripts/verify_docx_format.py /absolute/path/output.docx \
  --reference /absolute/path/reference.docx \
  --project "项目名称" \
  --subject "访谈对象" \
  --interview-type "专家访谈" \
  --date-compact YYYYMMDD
```

格式守门器必须确认：

- 文件名为`{项目名称}_{访谈对象}{访谈类型}纪要_{YYYYMMDD}.docx`
- 标题为`{项目名称}-{访谈对象}{访谈类型}`
- `styles.xml`、`numbering.xml`、`settings.xml`和主题文件未被改写
- 没有出现模板之外的字体；不得把黑体、楷体或宋体替换成Hiragino Sans GB、苹方、微软雅黑等字体
- 标题、元信息、主要结论、章节、子标题和要点的段落属性与run属性均来自模板
- 自动编号段落没有手写“一、”“1.”“➢”“-”等前缀
- 元信息没有`111`、`XXX`、`TBD`、“待补充”等占位值
- “访谈纪要”按模板设置受控分页

任一项失败都必须回到模板重新生成，不得通过手动改字体或仅改文件后缀绕过。

### 1. 逐页渲染检查

```bash
# 1. 转PDF
soffice --headless --outdir check --convert-to pdf 访谈纪要.docx

# 2. 提取文本(检查内容完整性)
pdftotext -layout check/访谈纪要.pdf check/text.txt

# 3. 转jpeg(检查排版/编号/emoji)
pdftoppm -r 100 check/访谈纪要.pdf check/p -jpeg
```

然后用Read工具查看 `check/p-1.jpg` 和 `check/p-{last}.jpg`,确认:

- ❌ 文件名、标题及日期是否符合标准命名协议
- ❌ 编号是否正确显示(1./2./3./...)
- ❌ 是否同时出现自动编号与手写编号
- ❌ 段落缩进是否正确(主要结论缩进/章节缩进/要点缩进三层)
- ❌ 粗体/正文字体是否正确切换
- ❌ emoji是否出现乱码块(LibreOffice下彩色emoji会变乱码,如出现立刻换成纯文字"■")
- ❌ 页眉/页脚是否有遗留模板内容
- ❌ 元信息表格是否正确显示
- ❌ “访谈对象及其背景介绍：”后是否手工换行；对象姓名、职务和职责是否与标签保持同段连续展示
- ❌ 是否有空白段落造成的奇怪间距
- ❌ “主要结论”结束后是否存在受控分页，“访谈纪要”是否从新页页首开始，PDF中是否出现重复分页造成的空白页
- ❌ 末页是否出现孤行、仅一两行成页或异常大片留白
